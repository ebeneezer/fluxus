# Fluxus 0.1.1

- Improved upload and download readability with semi-transparent backgrounds.
- Numeric graph readouts can now use the full inner graph width.
- Added configurable graph, color, font, LED, history, and interface options.
- Bundled native backend for Linux x86_64, compiled with `-O3`.
- Added installer, uninstaller, SHA-256 checksum, and complete corresponding
  source code.
